# Fluval BLE v1.0.0

v1.0.0 hardens Fluval BLE for the single-connection reality of these
fixtures: only one BLE central may hold a light at a time, so Home Assistant
now actively shares that connection responsibly and supervises the fixture's
onboard schedule instead of silently drifting out of sync with it.

## Highlights

- **Schedule Guardian**: a new active supervisor that, right after every
  reconnect and on a configurable interval, re-syncs the fixture's clock,
  corrects mode drift back to the expected Auto/Professional/Manual mode, and
  re-pushes the expected Auto/Professional schedule if the fixture's own copy
  has drifted. The on-device schedule remains the safety net and keeps
  running with zero Home Assistant involvement; the guardian is what notices
  and fixes it when reality and expectation disagree.
- **Manual override handling**: adjusting colour, effects, or power from Home
  Assistant while the guardian expects Auto/Professional is treated as a
  deliberate, temporary override rather than an error. The fixture is left in
  Manual mode for a configurable window (default 60 minutes, or indefinitely)
  before the guardian restores the expected schedule mode. A new **Return to
  schedule** button and `fluvalble.end_override` action end an override
  immediately.
- **Bluetooth connection switch**: a new always-available switch controls
  whether Home Assistant holds the fixture's single BLE connection slot open,
  so you can release it on demand for the Fluval app or another controller
  without removing the integration.
- **Guardian visibility**: new `sensor` entities for guardian status, last
  check time, and cumulative corrections; a `binary_sensor` that turns on
  after repeated failed corrections or extended unreachability, paired with a
  Home Assistant repair notification; and a `fluvalble.guardian_check_now`
  action to force an immediate check.
- New guardian options (expected mode, check interval, override return time,
  alert threshold) are configurable from the integration's **Configure**
  dialog alongside the existing connection settings.

## Upgrade notes

Guardian entities and the Bluetooth connection switch are added automatically
on upgrade with sensible defaults (expected mode: Auto, check every 10
minutes, override returns after 60 minutes, alert after 3 consecutive
failures) - no reconfiguration is required. Review **Configure** to adjust
them for your setup, especially if a fixture is deliberately run in Manual or
kept unsupervised.

If a fixture behaves differently after upgrading, include its exact model,
Home Assistant version, downloadable Fluval BLE diagnostics, and relevant
logs in a GitHub issue.
