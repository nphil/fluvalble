# Fluval BLE v1.0.2

v1.0.2 fixes a thread-safety bug in the Schedule Guardian's periodic runner.

## Fixed

- The guardian's interval check is now registered as a Home Assistant loop
  callback. `async_track_time_interval` runs a plain function in an executor
  thread, so every check interval created the check task from the wrong
  thread and Home Assistant logged "calls hass.async_create_task from a
  thread other than the event loop" (observed on a live install). A
  regression test pins the loop-dispatch marker on the registered callable.
