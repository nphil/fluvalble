# Fluval BLE v1.5.2

v1.5.2 makes sure the Fluval light can never slow down a Home Assistant restart,
even when the light is switched off, out of range, or the Bluetooth proxy is busy.

## Fixed

- **Restarts no longer wait for the light.** The first "is the light in the right
  mode?" check, and the one-time old-schedule conversion, used to be tasks that
  Home Assistant waited for before it said it had finished starting. Because that
  check connects to the light, a light that did not answer could hold startup open
  for a long time. They now run quietly in the background, so Home Assistant starts
  right away and the light's entities fill in as soon as it connects.

- **A stuck Bluetooth connection gives up faster.** If a connection attempt or a
  single Bluetooth step hangs, it is abandoned after 10 seconds (it used to be 30
  and 15) and tried again, so a light recovers sooner after a proxy hiccup.

## Notes

No settings, entities or actions changed. The light is still kept in the right
mode by the schedule guardian, exactly as before.
