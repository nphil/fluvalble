# Fluval BLE v1.1.1

v1.1.1 is a one-line correction to the v1.0.3 scheduled-level rendering.

## Fixed

- The light entity only derives `is_on` from the onboard schedule when the
  schedule actually produced a reading (`level_source: schedule`). When the
  level source is `unknown` (for example a Plant Pro fixture, which reports
  live state in every mode, with no active on-demand client) the entity keeps
  the fixture's reported on/off state instead of asserting off.
