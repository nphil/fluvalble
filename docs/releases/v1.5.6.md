# Fluval BLE v1.5.6

v1.5.6 makes the integration ready for Home Assistant 2026.11 and keeps working on 2026.10.

## Changed

- **Renaming an entity id is smoother on Home Assistant 2026.11.** Home Assistant now
  updates an entity in place when you change its id, instead of removing and adding it
  again. Every Fluval entity opts in, so the light's Bluetooth link is never touched by a
  rename.
- **Options flow cleanup.** The settings dialog always uses Home Assistant's built-in
  reload after saving; an old fallback that would become an error in Home Assistant
  2026.12 was removed.
- Device registry lookups use the current Home Assistant fields.
- The integration now lists its categories (lighting, pets) for the HACS store.

## Fixed

- On Home Assistant 2026.10 and earlier, renaming a schedule status, corrections,
  schedule problem or return-to-schedule entity made it stop updating until the next
  reload. It keeps updating now.

## Notes

No settings, entities or actions were added or removed. The repository now also runs its
tests against real Home Assistant (stable and beta) every week.
